# Security

This repository is pre-release. No production support or isolation certification
is claimed. Do not report keys, learner records or exploitable private deployment
details in public issues. Use the ElevenID organization security policy and
GitHub private vulnerability reporting when enabled.

Never submit live credentials in tests. Review changes to the operation
registry, transport, configuration, exports, dependency lock, workflows and
network policy as security-sensitive. The standard CI job must pass; enabling
branch protection, secret scanning and push protection is a separate repository
administration task and is not implied by the presence of these files.
